# Mac Terminal Practice

A macOS Terminal practice repository focused on building confidence with the command line in real-world development and automation workflows.

## Goal

Build practical Terminal skills for common backend development and AI automation tasks, including:

- navigating and organizing files;
- reading, searching, and editing files;
- using Git and GitHub from the command line;
- managing environment variables and secrets safely;
- testing APIs with `curl`;
- working with Docker, shell scripts, SSH, permissions, and scheduled automation.
